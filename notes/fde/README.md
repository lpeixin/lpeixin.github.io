# 笔记知识库

> 一个从 [lpeixin.github.io](https://lpeixin.github.io/) 「学习笔记」板块点进来的文档型子页面。
> 基于 [Docsify](https://docsify.js.org/)，纯静态、无需构建，直接编辑 Markdown 即可。

这里是知识库的**首页**。你可以把它当成目录、导读，或者一篇总览笔记。

## 这个页面能做什么

- 左侧边栏导航、顶部全文搜索、底部「上一篇 / 下一篇」翻页
- Markdown 写作，代码块自动高亮并可一键复制
- Mermaid 流程图、KaTeX 数学公式、图片点击放大
- 右下角按钮可切换深色 / 浅色主题，选择会被记住

## 快速上手

1. 打开同目录下的 `_sidebar.md`，改标题、加链接。
2. 在 `docs/` 里新建 `.md` 文件写正文。
3. 侧边栏里加一行 `- [标题](docs/你的文件.md)`。
4. 想再开一个知识库，把整个 `notes/fde/` 目录复制成 `notes/新名字/`，
   然后回到主页 `assets/js/content.js` 的 `notes.items` 里加一条入口。

详细步骤见 → [如何使用这个模板](/docs/如何使用这个模板.md)
