# 第二章 · 动手实践

这一章演示「步骤型」笔记怎么写：命令、输出、踩坑记录。

## 步骤

1. 初始化环境：

   ```bash
   git clone https://github.com/lpeixin/lpeixin.github.io
   cd lpeixin.github.io
   python3 -m http.server 8080
   ```

2. 打开 `http://localhost:8080/notes/fde/index.html` 预览。

3. 编辑 `docs/` 下的 Markdown，保存后浏览器刷新即可看到变化。

## 踩坑记录

- **直接双击 `index.html` 打不开正文**：Docsify 靠 `fetch` 读 `.md`，`file://` 协议会被 CORS 拦截，必须用本地 HTTP 服务。
- **中文文件名**：可以用，但为了链接稳定，建议 URL 里保持能正确编码；发布前点一遍链接确认。
- **相对路径**：本项目开启了 `relativePath: true`，`[链接](docs/xxx.md)` 会相对当前文件解析。
