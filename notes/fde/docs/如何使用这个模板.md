# 如何使用这个模板

这是一份「照着做就行」的说明。目标是让你**只碰 Markdown 文件**就能扩充这个知识库。

## 目录结构

```
notes/fde/
├── index.html        # Docsify 外壳：一般不用动
├── _sidebar.md       # 左侧导航清单 = 你的目录
├── README.md         # 首页（homepage）
└── docs/             # 所有正文页面都放这里
    ├── 如何使用这个模板.md   ← 你正在看
    ├── 第一章-概述.md
    ├── 第二章-动手实践.md
    └── 附录-图表与公式.md
```

## 加一篇新笔记

1. 在 `docs/` 里新建一个文件，比如 `docs/MCP-手记.md`。
2. 用 Markdown 写正文（标题、代码块、表格都支持）。
3. 打开 `_sidebar.md`，在合适的分组下加一行（链接以 `/` 开头，写成根绝对路径）：

   ```markdown
   - [MCP 手记](/docs/MCP-手记.md)
   ```

保存后刷新页面就会出现在左侧目录里，并自动进入搜索索引和上/下篇翻页。

## 再开一个独立的知识库

想给「另一个主题」单独做一个文档站（比如 Swift、量化）：

1. 把整个 `notes/fde/` 目录复制一份，改名，例如 `notes/swift/`。
2. 进入新目录，改 `index.html` 里的 `name`（左上角标题）和 `repo`。
3. 重写 `README.md`、`_sidebar.md` 与 `docs/` 内容。
4. 打开主页配置 `assets/js/content.js`，在 `notes.items` 数组里加一条入口：

   ```js
   {
     title:   { zh: "Swift 笔记", en: "Swift Notes" },
     summary: { zh: "一句话简介", en: "One-line intro" },
     url:     "notes/swift/index.html",   // 相对路径 = 同标签打开
     count:   8,                          // 可选：文档篇数
     date:    "2026-10",                  // 可选：更新时间
     tags:    ["Swift", "macOS"]          // 可选：卡片标签
   }
   ```

主页「学习笔记」板块会自动多出一张卡片。

## 本地预览

Docsify 通过 `fetch` 加载 Markdown，需要本地起一个静态服务器（直接双击 `index.html` 会因为跨域策略失败）。在项目根目录任选一种：

```bash
# 方式 A：Python
python3 -m http.server 8080
# 然后访问 http://localhost:8080/notes/fde/index.html

# 方式 B：Node（若已安装）
npx serve .
```

## 部署

本仓库是 GitHub Pages 静态站。把文件提交并推送到 `main` 分支，Pages 生效后即可通过
`https://lpeixin.github.io/notes/fde/#/` 访问。URL 里的 `#/` 是 Docsify 的 hash 路由。

## 常用写作语法速查

| 想做的事 | 写法 |
| --- | --- |
| 代码块高亮 | ` ```python ` 围栏 |
| 行内代码 | `` `code` `` |
| 表格 | 标准 Markdown 表格 |
| 引用块 | `>` 开头 |
| 站内链接 | `[标题](/docs/xxx.md)`（以 `/` 开头） |
| 外部链接 | `[标题](https://…)` |
| 图片 | `![alt](assets/pic.png)`，点击可放大 |
| Mermaid 图 | 用 ` ```mermaid ` 代码块（见附录） |
| 数学公式 | 行内 `$…$`，块级 `$$…$$`（见附录） |
